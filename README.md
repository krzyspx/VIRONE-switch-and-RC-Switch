# VIRONE-switch-and-RC-Switch
RC-switch for VIRONE switch recive /send code
A modified version of the RCSwitch library (based on sui77/rc-switch) along with a receive example sketch for 433 MHz RF signals on AVR, ESP8266, and ESP32 microcontrollers.   
Contents:RC.h & RC.cpp – RCSwitch header and implementation including the protocol table (with a moj VRONE entry), 
interrupt handling (handleInterrupt), buffer overflow protection, and transmit/receive methods.ReceiveDemo_Advanced_VRONE.ino – example receiver sketch using RC.h.
